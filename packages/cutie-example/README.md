# @openstax/cutie-example

Example application demonstrating QTI v3 assessment items using the Cutie libraries.

## Development

```bash
# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## CI Scripts

```bash
# Run all CI checks
npm run ci

# Individual checks
npm run ci:lint
npm run ci:typecheck
npm run ci:spelling
```
